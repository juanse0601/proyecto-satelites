# proyecto-satelites
1)datos\satelites.json tiene los datos de los satelites en formato .json
2)satelite.py contiene el objeto satelite y una funcion para guardar
    en una lista los satelites
3)analisis.py tiene las funciones para trabajar con el objeto satelites
4)catalogo.py trabaja con el archivo satelites.json
5)funciones_base.py contiene las funciones para crear los satelites usando 
    skyfield 
6)Informe.ipynb contiene un resumen(Como texto o como graficos) haciendo uso 
    de todas las funciones.
